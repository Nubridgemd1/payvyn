5Current capabilities & what's pending for production

Working now

  • Digital onboarding flow end to end (member journey).
  • Native bank linking across 4,100+ U.S. institutions (real directory + ABA).
  • Automatic address population (real).
  • Native ownership verification — real deployed backend (sandbox), attempt-limited.
  • Core operations console (tracking, reconciliation, fraud, reporting).
  • Secure, installable PWA at payvyn.org (HTTPS).

Pending for real money movement

  • Identity / KYC — simulated; connect the CU's CIP or a provider. PENDING
  • ACH / FedNow movement — simulated; needs the CU's ACH origination (ODFI). PENDING
  • Verification → production — flip ACH_MODE=production + the CU's ACH config. PENDING
  • Core integration — console is local; wire the core connector for crediting/reconciliation. PENDING
  • Shared backend for onboarding/ops — move from browser storage to a secure DB. PENDING
Readiness: the member-facing layer and the ownership-verification backend are built and deployed. Going live for real money movement is a configuration-and-integration effort with the credit union (ACH origination + core), not a ground-up build.
